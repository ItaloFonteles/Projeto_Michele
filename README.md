# ⚖️ Landing Page - Dra. Michele Fonteles

Uma página web profissional, moderna e responsiva desenvolvida para apresentar os serviços advocatícios da Dra. Michele Fonteles, com foco nas áreas Previdenciária, Trabalhista e Penal.

## 🚀 Funcionalidades

* **Design Responsivo:** Layout adaptável a qualquer tamanho de ecrã (computadores, tablets e telemóveis).
* **Integração com WhatsApp:** Botões de "Call to Action" (CTA) que redirecionam o cliente diretamente para o WhatsApp com uma mensagem inicial automática.
* **Efeito Parallax:** Secção de "Áreas de Atuação" com imagem de fundo fixa, proporcionando uma navegação fluida e sofisticada.
* **Mapa Interativo:** Integração em ecrã total com o Google Maps para facilitar a localização do escritório.
* **UI/UX Elegante:** Paleta de cores focada em tons escuros (Azul Marinho) com detalhes em dourado para transmitir autoridade, tradição e confiança.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, variáveis nativas (`:root`), Flexbox, CSS Grid e Media Queries para responsividade.
* **Google Fonts:** Tipografia clássica e moderna (*Cormorant Garamond* para títulos e *Montserrat* para leitura).
